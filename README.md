Selamat datang di repositori **JavaFX Product Management**! 🚀 

Aplikasi ini adalah sistem manajemen pencatatan produk toko berbasis desktop yang dibangun menggunakan **JavaFX** dengan arsitektur **MVC (Model-View-Controller)** yang rapi dan terstruktur. Aplikasi ini dirancang tidak hanya untuk fungsionalitas, tetapi juga dengan *User Interface* (UI) yang modern, interaktif, dan memanjakan mata melalui kustomisasi CSS yang mendalam.

---

## ✨ Fitur Utama

- **📦 Manajemen Produk (CRUD):** Tambah, lihat detail, dan hapus data produk dengan mudah.
- **🖼️ Lampiran Gambar Lokal:** Mendukung unggah gambar produk (PNG/JPEG) langsung dari direktori lokal menggunakan `FileChooser`.
- **🔍 Pencarian Dinamis:** Filter dan cari produk spesifik berdasarkan nama produk secara instan.
- **🎨 UI/UX Modern:** Antarmuka elegan dengan efek *hover*, bayangan (*dropshadow*), dan elemen visual yang rapi menggunakan JavaFX CSS.
- **🛡️ Validasi Data:** Memastikan integritas data (contoh: harga tidak boleh huruf, input tidak boleh kosong) dengan notifikasi *error* yang ramah pengguna.
- **💡 Tanpa Database (In-Memory):** Data dikelola secara langsung di dalam RAM menggunakan `ObservableList` (sangat cocok untuk tujuan pembelajaran dan prototipe cepat).

## 🛠️ Teknologi yang Digunakan

- **Bahasa:** Java (JDK 17+)
- **GUI Framework:** JavaFX 21
- **Build Tool:** Apache Maven
- **Pola Arsitektur:** MVC (Model-View-Controller)

## 🚀 Cara Menjalankan Aplikasi

Ingin mencoba aplikasi ini di komputermu? Ikuti langkah-langkah mudah berikut:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/username-kamu/nama-repositori-kamu.git
   ```
2. **Buka proyek di IDE** (NetBeans, IntelliJ IDEA, atau VS Code).
3. **Pastikan JDK 17 atau yang lebih baru sudah terinstal.**
4. **Jalankan menggunakan Maven:**
   ```bash
   mvn clean javafx:run
   ```
